# BioGas Inc.

By Mohammed Anwar. Live site: https://ghost545a.github.io/biogas-inc/

An interactive 3D walkthrough (English and Arabic) of how livestock manure in the
22 Arab countries can become biogas for cooking and fertiliser for fields.

- `index.html` — English, narrated in a British voice
- `ar.html` — Arabic (MSA + Yemeni narration)

Livestock numbers: FAOSTAT 2024. Biogas figures are estimates (30% of manure
collected, 1.5 m³ of biogas per household per day). 3D scene: three.js.
Narration generated with VoiceStudio. A how-to guide and the method are coming soon.
